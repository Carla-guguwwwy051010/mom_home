# 妈妈的小屋

一个直接在浏览器运行的真实三维互动小屋。最终文件为 `dist/mom-home-complete.html`，脚本、模型生成代码、四幅绘本插画与二十张安慰卡片均已内嵌，不需要服务端或联网。

## 体验

- 小女孩在门前等待，发现妈妈后跑来拥抱；可以只抱一下，或牵手、开门、一起回家。
- 妈妈采用第一人称视角。拥抱和牵手时有接触人物的手臂模型。
- 小屋包含沙发、灯、窗帘、茶具、卡片机和相框。拖动空白处可以稍微转动镜头。
- 茶壶倾斜倒茶，茶水渐渐升高，热气上升。可以举杯喝茶、添茶和返回小屋；沙发也可以点击进入喝茶体验。
- 独立花园有花坛、长椅、拱门和小路。浇水会出现水滴与飞溅，种花及浇水会推动花朵成长。每次打开也记录一次回家与一份种花心意；花园最多显示 12 株，累计记录保留。
- 卡片机有二十张不同寄语，每组二十张不重复，跨组首张也避免与上一张相同。已经抽到的卡片会出现在收藏中。
- 照片墙可以选择 1–4 张本地照片，图片会缩小后保存在当前浏览器中，不上传到任何服务。
- 可开启轻柔提示音、减少动作与镜头移动。系统的减少动态效果偏好也会自动应用。
- 上午、黄昏和夜晚使用不同的天空与窗户颜色。
- 界面采用奶油纸张与柔和玫瑰色，卡片、按钮和提示统一圆角与间距。手机上的小屋导航横向排列，给三维场景留出更多空间。角色步伐与场景灯光也经过柔化。

## 本地记录

使用 `localStorage` 的 `mom-home-v3` 保存回家次数、花园记录、喝茶次数、卡片收藏和照片。同一浏览器、同一路径打开文件有助于继续读取原来的记录。浏览器禁止存储或空间不足时，页面会明确提示，并允许继续在当前打开期间使用。
从旧版四张卡片升级时，原有收藏会保留；抽卡袋会重新洗牌，以便新卡片立即有机会出现。

## 模型与素材

角色是实际的三维网格，包含可运动的肩、肘、髋、膝和手部，并支持眨眼；头发、贴合脸部的眼睛、褶皱裙摆、蕾丝和鞋扣也是真实几何。脸颊、眼窝、鼻梁和下巴做在连续脸部网格内；眼睛开口更接近柔和的杏仁形，眼睑扫过眼睛完成眨眼，嘴角贴合脸部轮廓且在拥抱时微微展开。额前发束收细，并补了脸侧的细发丝。它是依据用户参考方向制作的程序化娃娃，尚未达到参考图中经过精细雕刻与毛发处理的角色品质，也不是从参考图片自动恢复出的同一个角色资产。

第一张拥抱插画来自用户提供的图片。陪伴、递茶、送花三幅通过内置图片生成工具制作：米白纸张、轻柔彩铅水彩、深色发髻的妈妈和粉裙女儿，无文字。二十张卡片按主题共用这四幅插画，每张的标题与中文寄语都不同，并由页面排版呈现。

## 开发

需要 Node.js 20 或更新版本。

```sh
npm ci
npm test
npm run build
```

源文件：

- `app-complete.js`：页面状态、动作顺序、互动与镜头。
- `character.js`：小女孩几何与关节。
- `world.js`：门外、小屋、家具和卡片机。
- `garden.js`：花园生长、浇水与水滴。
- `tea.js`：倒茶、热气、举杯。
- `state.js`：收藏与进度保存。
- `cards.js`：二十张卡片的标题、寄语与插画主题。
- `motion.js`：逐帧推进的动作顺序，防止跳过开门等步骤。
- `page.html`：页面布局与可访问的原生对话框。
- `build.mjs`：打包成单文件 HTML。

## 验证范围

已测试本地记录恢复、损坏/禁用存储、卡片不重复、动作不串帧、茶水与浇水动画、三维几何有限值、场景构造，以及从门口到小屋、喝茶、花园、卡片收藏和返回的逻辑流程。流程测试使用真实场景对象、模拟 DOM 和渲染器，不等同于浏览器画面、性能或移动设备实测。本环境的浏览器安全策略阻止了本地文件画面验收，未绕过该限制。
